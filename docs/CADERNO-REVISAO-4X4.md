## Procedimento de revisão

1. Conferir configuração real do veículo/componente, aplicabilidade e riscos.
2. Registrar documentação técnica e versão; não aceitar somente texto gerado por IA como evidência.
3. Registrar responsável, data e decisão individual (aprovar, corrigir, rejeitar ou manter pendente).
4. Atualizar `knowledge/offroad.json` somente após decisão documentada; adicionar teste de regressão para cada mudança relevante.
5. Executar testes locais e aguardar o GitHub Actions antes de considerar a alteração publicada.
