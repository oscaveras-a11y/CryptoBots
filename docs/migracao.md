# Migração do módulo 4X4 para VERIS-AI

A base off-road foi transferida do Trilha 4X4 para a VERIS-AI. O conjunto original possui 50 perguntas consolidadas em 49 registros, com 13 entradas inicialmente confirmadas e 36 pendentes de revisão; somente as confirmadas são usadas automaticamente. Há também orientação geral adicional para troca segura de pneu, que não deve ser confundida com aprovação técnica das pendências.

O adaptador de integração já está implementado no backend do Trilha 4X4, mas o funcionamento conjunto no PC e no celular ainda exige testes reais. A identidade pública é **VERIS-AI**; **4X4** designa o módulo especializado. Identificadores internos como `VERIS_API_KEY`, `VERIS_URL` e o nome do repositório `IA-VERIS` são preservados para compatibilidade.
